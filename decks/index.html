Decks

Historical decks, read in their own language.

A Marseille pip is a number and a suit. A Smith pip is a scene. Each deck is read the way it was drawn.

London · 1909 Rider–Waite–Smith Pamela Colman Smith drew all 78 cards, with a scene on every pip. Read as scenes. Every plan
France · 17th–18th century Tarot de Marseille Woodcut pattern with patterned pips. Read by number and suit. Every plan
Italy · c. 1490s Sola Busca The oldest complete tarot deck known, with illustrated pips. Seeker and Oracle
Milan · 15th century Visconti–Sforza Hand-painted for a ducal court. Not every card survives; we read the ones that do. Seeker and Oracle
Paris · c. 1650 Tarot de Viéville A rare Parisian pattern with its own take on familiar cards. Seeker and Oracle
